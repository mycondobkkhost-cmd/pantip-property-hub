    คอมที่ทำงาน: กำลังเช็ค…
    บัญชีเฟส: —
    —
    —
    ขั้นที่ 1 — ใส่บัญชีเฟสส่วนตัวที่จะไปคอมเมนต์
    1. ใช้อีเมล/เบอร์ + รหัสผ่านของเฟสส่วนตัวที่ต้องการให้ไปคอมเมนต์ (ไม่ใช่บัญชีเพจ)
    2. กรอกในช่องด้านล่าง แล้วกด บันทึกบัญชีเฟส
    3. ถ้าเปลี่ยนรหัสผ่านทีหลัง ให้ใส่รหัสใหม่แล้วกดบันทึกอีกครั้ง
    ขั้นที่ 2 — เปิดระบบบนคอมที่จะทำงาน

    เลือกคอมเครื่องหนึ่งที่จะเปิดทิ้งไว้ · กดดาวน์โหลดตามระบบ · ไฟล์ตั้งค่าให้แล้ว ไม่ต้องพิมพ์รหัสเอง

    น้องแอดมินทำแค่เปิดไฟล์: ระบบจะดาวน์โหลดโค้ด + ไลบรารี + เบราว์เซอร์ให้อัตโนมัติในครั้งแรก (ใช้เวลาหลายนาที — อย่าปิดหน้าต่าง)

    วิธีเปิดบน Windows (ให้น้องแอดมิน)
    1. กดปุ่มดาวน์โหลด Windows ด้านล่าง → ส่งไฟล์ให้น้องแอดมิน (แชท/เมล/USB ก็ได้)
    2. บนคอมน้อง: ดับเบิลคลิกไฟล์「เปิดระบบคอมเมนต์」
      ถ้า Windows กัน: กด More info → Run anyway
    3. ครั้งแรกหน้าต่างดำจะเตรียมระบบเอง — รอให้เสร็จ อย่าปิด
    4. พอสถานะใน Hub ขึ้น「ทำงานอยู่」= พร้อม
    ไม่ต้องย้ายไฟล์ · ไม่ต้องติดตั้งอะไรเอง · แค่เปิดทิ้งไว้แล้วดูสถานะใน Hub
    วิธีเปิดบน Mac
    1. กดปุ่มเขียว ดาวน์โหลดไฟล์เปิดระบบ (Mac) → ไฟล์ลง Downloads
    2. เปิด Downloads → คลิกขวา ไฟล์「เปิดระบบคอมเมนต์」→ เปิด → กดเปิดอีกครั้ง
      ถ้าขึ้นข้อความเหลือง: กด「เสร็จสิ้น」แล้วคลิกขวา → เปิด อีกครั้ง (หรือ การตั้งค่าระบบ → ความเป็นส่วนตัว → Open Anyway)
    3. ครั้งแรกอาจเตรียมระบบเอง — รอให้เสร็จ อย่าปิดหน้าต่าง
    4. กลับมาหน้านี้ สถานะควรขึ้น「ทำงานอยู่」
    ไม่ต้องย้ายไฟล์ · ระบบเตรียมโค้ด/ไลบรารี/เบราว์เซอร์ให้อัตโนมัติ
    ขั้นที่ 3 — ล็อกอินเฟสครั้งแรก
    1. ตรวจว่าขั้นที่ 2 เปิดอยู่ (สถานะ「ทำงานอยู่」)
    2. กดปุ่มเปิดหน้าต่างล็อกอินเฟส
    3. บนคอมที่เปิดระบบไว้ จะมีหน้าต่าง Facebook เด้ง — มี 2FA ให้ใส่ที่เครื่องนั้น
    4. พอขึ้น「ล็อกอินแล้ว」→ ไปแท็บ คอมเมนต์กลุ่ม เพื่อเพิ่มคิว
    ถ้ามีปัญหา — อ่านตรงนี้
    • 「ยังไม่เปิด」= ยังไม่ได้เปิดไฟล์ หรือปิดหน้าต่างไปแล้ว → เปิดใหม่
    • Mac ขึ้นข้อความเหลือง = กดเสร็จสิ้น แล้วคลิกขวา → เปิด (อย่าดับเบิลคลิกอย่างเดียว)
    • หน้าต่างขึ้น error เรื่อง Browser/Executable = ปิดแล้วเปิดไฟล์ใหม่ ระบบจะดาวน์โหลดเบราว์เซอร์ให้อัตโนมัติ
    • ขึ้นว่าไม่มี Python = ติดตั้งตามลิงก์ที่ไฟล์เปิดให้ แล้วเปิดไฟล์อีกครั้ง (Windows มักติ๊ก Add to PATH)
    • ดาวน์โหลดโปรเจกต์ไม่สำเร็จ = เช็คเน็ตแล้วเปิดไฟล์ใหม่
    • กดล็อกอินแล้วไม่เด้งเฟส = ขั้นที่ 2 ยังไม่เปิด หรือรอให้เตรียมระบบครั้งแรกเสร็จก่อน

    วิธีใช้ 1) เปิดลิงก์「โพสต์บนเพจ」ของทรัพย์นี้
    2) คัดลอกข้อความประกาศทั้งดุ้นจากเพจ (อย่าตัดท้าย)
    3) วางในช่องนี้ แล้วกด「บันทึกต้นฉบับ」
    4) เลื่อนลงไปที่กลุ่มแนะนำ → กด「โพสต์」 → ระบบคัดลอกข้อความ (กันซ้ำ) + เปิดกลุ่ม
    5) ใน Facebook วางข้อความ (Cmd/Ctrl+V) → เพิ่มรูปเอง → กดเผยแพร่
    6) คัดลอกลิงก์โพสต์กลุ่มที่ได้ แล้ววางในช่อง「บันทึกลิงก์โพสต์กลุ่ม」ด้านล่าง เพื่อเข้าคิวคอมเมนต์อัตโนมัติ
