เฟส Ops — แจ้งเคสค้าง / สั่งฟอโล่ว (Pantip Property LINE)
============================================================

เป้าหมาย
- บอทไม่ต้องตอบลูกค้าเองก่อน (LINE_AUTO_REPLY=0)
- มีกลุ่มคุณ + แอดมิน เป็นศูนย์คุมเคส
- บอทแจ้งเมื่อมีแชทรอตอบ / สรุปเคสค้างจาก audit
- คุณหรือแอดมินสั่ง “ทัก …” เพื่อให้บอทส่งข้อความหาลูกค้าได้

------------------------------------------------------------
0) โหมดเวลางานบน Mac นี้ (แนะนำ — ไม่เสียเงิน cloud)
------------------------------------------------------------

เช้า (เริ่มงาน): ดับเบิลคลิก
  line_bot/เริ่ม Ops เวลางาน.command

เย็น (เลิกงาน): ดับเบิลคลิก
  line_bot/หยุด Ops เวลางาน.command

สคริปต์จะ:
- เปิดบอท + tunnel + ตั้ง webhook ให้ LINE อัตโนมัติ
- กัน Mac หลับระหว่างบอทรัน (caffeinate) — แนะนำเสียบชาร์จตอนทำงาน
- ถ้า tunnel หลุด จะซ่อมเอง (ต้องล้ม 2 ครั้งติดกัน)

(แนะนำครั้งเดียว) สมัคร ngrok ฟรี แล้วใส่ใน .env:
  NGROK_AUTHTOKEN=...
  จาก https://dashboard.ngrok.com/get-started/your-authtoken
  → tunnel จะนิ่งกว่า Cloudflare ฟรีมาก

นอกเวลางาน: ปิดบอทได้ — ลูกค้าทักจะไม่เข้า ops จนกว่าจะเปิดเช้าวันรุ่งขึ้น

------------------------------------------------------------
1) ตั้งค่า .env
------------------------------------------------------------

LINE_AUTO_REPLY=0
LINE_OPS_ALERT_LIVE=1
LINE_OPS_GROUP_ID=Cxxxxxxxx   # group id ของกลุ่มแอดมิน
LINE_ADMIN_USER_IDS=Uxxxx,Uyyyy  # (ทางเลือก) user id แอดมินที่คุย DM กับ OA ได้

วิธีได้ Group ID
1. สร้างกลุ่ม LINE ระหว่างคุณ + นัท/เพลง + เชิญ OA @ptp.condo เข้ากลุ่ม
2. ในกลุ่ม พิมพ์อะไรก็ได้หนึ่งข้อความ
3. ดู log ของบอท หรือชั่วคราวดู event ใน webhook — groupId ขึ้นต้นด้วย C
   (หรือใช้เว็บดึง group id จาก Messaging API / webhook body)

------------------------------------------------------------
2) นำเข้าเคสจาก audit ที่อ่านมาแล้ว
------------------------------------------------------------

cd โปรเจกต์
source .venv/bin/activate
python scripts/import_audit_cases.py

ได้ไฟล์: data/line_cases.json

ดูสรุปในเครื่อง:
python scripts/send_ops_digest.py
(ถ้ายังไม่มี LINE_OPS_GROUP_ID จะพิมพ์ในเทอร์มินัลอย่างเดียว)

------------------------------------------------------------
3) คำสั่งในกลุ่มแอดมิน
------------------------------------------------------------

สรุป / เคสค้าง
  → รายการลืมตอบ + เคสค้าง

ฟอโล่ว <ชื่อ>
  → รายละเอียดเคส + ข้อความแนะนำ
  → ถ้ามี user_id แล้ว จะบอกคำสั่ง ทัก ให้คัดลอก

ทัก <userId> <ข้อความ>
  → ส่งหาลูกค้าทันทีผ่าน OA
  ตัวอย่าง:
  ทัก U1234... สวัสดีค่ะ Admin นัท กลับมาอัปเดตห้องให้นะคะ

ปิดเคส <ชื่อ>
  → มาร์คว่าจบแล้ว

ลิงก์ <ชื่อ> <userId>
  → ผูกชื่อจาก audit กับ LINE user id จริง
  (จำเป็น เพราะแชทเก่าจาก chat.line.biz ไม่มี user id)

ช่วยเหลือ
  → แสดงคำสั่งทั้งหมด

------------------------------------------------------------
4) พฤติกรรมตอนลูกค้าทัก OA (เมื่อบอทรัน + webhook เปิด)
------------------------------------------------------------

- บันทึกแชท + อัปเดตเคสใน data/line_cases.json
- ถ้าสถานะ = ลืมตอบ → แจ้งเข้ากลุ่ม ops (LINE_OPS_ALERT_LIVE=1)
- ไม่ตอบลูกค้าอัตโนมัติ จนกว่า LINE_AUTO_REPLY=1

ดูเคสผ่าน API เครื่อง:
GET http://127.0.0.1:8787/ops/cases?status=unreplied
GET http://127.0.0.1:8787/ops/cases?role=end_customer&status=unreplied

------------------------------------------------------------
5) ขั้นตอนที่คุณทำต่อ (ครั้งเดียว)
------------------------------------------------------------

[ ] สร้างกลุ่มแอดมิน + เชิญ OA
[ ] เปิด 「เริ่ม Ops เวลางาน」 แล้วพิมพ์อะไรในกลุ่ม 1 ครั้ง → เอา groupId (C...) ใส่ LINE_OPS_GROUP_ID
[ ] รัน import_audit_cases.py (ทำแล้วถ้ามี data/line_cases.json)
[ ] ทดลองพิมพ์ "สรุป" ในกลุ่ม
[ ] (ทางเลือก) ใส่ NGROK_AUTHTOKEN ให้ tunnel นิ่ง
[ ] อย่าเปิด LINE_AUTO_REPLY=1 จนกว่า FAQ จะผ่านตรวจ
