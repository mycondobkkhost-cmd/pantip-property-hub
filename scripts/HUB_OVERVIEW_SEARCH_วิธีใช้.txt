Property Hub — ค้นหาบนแท็บ「ทรัพย์รวม」
======================================

ชีทหลัก:
https://docs.google.com/spreadsheets/d/1UUJFSj069k0XuPDWRJILYRes40amuQRxGpcGChITNjc/edit
แท็บ: ทรัพย์รวม

ทำอะไรได้
---------
แถว 1–5 = แถบค้นหา (chrome) · แถว 5 = หัวคอลัมน์สีทองเหมือน「ชีตสำหรับทำงาน」(#fbbc04)
- C2 = ค้นหาทั่วไป (รหัส / ชื่อโครงการ)
- C3 = ค้นหาทำเล / BTS·MRT
- ว่างทั้งคู่ = แสดงทั้งหมด · กรอกทั้งคู่ = AND
- ผลลัพธ์เริ่มที่แถว 6 (สูตร FILTER)

ข้อมูลซิงค์จากแอปอยู่ที่แท็บซ่อน `_overview_src`
แท็บ「ทรัพย์รวม」อ่านผ่าน FILTER — ซิงค์ครั้งถัดไปจะไม่ทับแถบค้นหา

ติดตั้ง / ซ่อม (ไม่ต้อง Apps Script)
------------------------------------
.venv/bin/python scripts/install_overview_search_chrome.py
.venv/bin/python scripts/install_overview_search_chrome.py --resync

หรือกด「ซิงค์ไปชีท Hub」ในแอป — sheet_write จะติดตั้ง chrome อัตโนมัติถ้ายังไม่มี

Apps Script (ทางเลือก)
----------------------
scripts/google_apps_script_hub_dashboard.gs — รีเฟรชแบบสคริปต์ (อ่านชีตสำหรับทำงาน + ทรัพย์ Hub)
ปกติไม่ต้องติดตั้งถ้าใช้ FILTER ด้านบนแล้ว

ดึงจาก「ชีตสำหรับทำงาน」
------------------------
pull ยังอ่านแท็บ「ชีตสำหรับทำงาน」ตามเดิม — ไม่แตะ「ทรัพย์รวม」
