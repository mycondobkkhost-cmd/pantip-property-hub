      รหัสที่เตรียมไว้สำหรับโพสกลุ่มอัตโนมัติ — เพิ่มที่นี่ แล้วดึงไปใช้ในแท็บโพสได้ทันที

        รหัสที่เตรียมไว้สำหรับคอมเมนต์กลุ่มอัตโนมัติ — เพิ่มที่นี่ แล้วดึงไปใส่คิวคอมเมนต์ได้ทันที

          คิวรอแอดมินโพสต์ · 「เพิ่มโพส」เปิดฟอร์มทรัพย์ · ลิงก์ซ่อนไว้กดไอคอน · ดึงจากชีทแท็บรอโพสต์

          เพิ่มคิวรอโพสต์
          เพิ่มโพส ลบ วันที่เพิ่ม โครงการ ราคา หมายเหตุ ลิงก์ต้น ลิงก์เจ้าของ

          คิวงานติดตามทรัพย์ — ดูว่าวันนี้ต้องทำอะไร · ทรัพย์ถึงรอบติดตามแยกจากใกล้หมดสัญญา

          1) ภาพรวมแบบเร็ว

          ตัวเลขหลักที่ควรดูก่อน — ไม่ต้องอ่านศัพท์เทคนิค

          2) คนเข้าเว็บมากน้อยแค่ไหน

          กราฟด้านล่างยิ่งสูง วันนั้นยิ่งมีคนเข้าเว็บโคเอเจนต์เยอะ

          จำนวนครั้งที่เปิดหน้าเว็บ ต่อวัน

          นับทุกครั้งที่มีคนเปิดหรือกลับมาที่หน้าโคเอเจนต์

          3) คนมาจากไหน

          ช่วยดูว่าโฆษณา/โพสต์ช่องทางไหนพาคนเข้ามาได้จริง

          ช่องทางที่มา

          เช่น โฆษณาเฟส, กูเกิล, ไลน์, หรือพิมพ์ลิงก์ตรง

          ชื่อแคมเปญโฆษณา

          ชื่อชุดโฆษณาที่ใส่ไว้ในลิงก์ (ถ้ามี)

          ประเภทสื่อ

          เช่น โฆษณาแบบเสียเงิน, โซเชียล, อีเมล

          คลิกจากโฆษณาแพลตฟอร์มไหน

          ระบบจับได้เมื่อคนกดโฆษณา Google / Facebook / TikTok แล้วเข้าเว็บ

          เว็บหรือแอปที่ส่งคนมา

          เช่น facebook.com, line.me หรือเข้าตรงๆ

          ชื่อแหล่งที่ใส่ในลิงก์

          ค่าที่ทีมใส่ตอนยิงลิงก์ เช่น facebook, google, line

          4) คนสนใจแค่ไหน / ทำอะไรบ้าง

          ดูว่าเข้ามาแล้วแค่แวะ หรือใช้งานจริง เช่น กดหาห้อง, กดไลน์, คัดลอกรหัส

          สิ่งที่คนทำบนเว็บ

          เรียงจากทำบ่อยไปน้อย

          เลื่อนหน้าจอลงไปไกลแค่ไหน

          ยิ่งถึง 75–100% แปลว่าอ่าน/ดูรายการค่อนข้างลึก

          ใช้มือถือหรือคอม

          ช่วยตัดสินใจว่าโฆษณาควรเน้นมือถือหรือคอม

          เปิดด้วยโปรแกรมอะไร

          เช่น Safari, Chrome, แอปในมือถือ

          5) ช่วงเวลาที่คนเข้าเยอะ

          ดูชั่วโมงไหนคึกคัก เพื่อยิงโฆษณาหรือโพสต์ในช่วงนั้น

          ชั่วโมงที่คนเข้าเว็บ (เวลาไทย)

          เลือกคอมเครื่องใดเครื่องหนึ่งเปิดทิ้งไว้ (Windows หรือ Mac) · ไม่ต้องบันทึกรหัสเฟสใน Hub · ระบบเตรียมโปรแกรมให้อัตโนมัติ

          กำลังตรวจว่าคอมเครื่องนี้เป็นระบบอะไร…

          Windows — เปิดบนคอมเครื่องนี้ หรือส่งให้น้อง
          1. กดดาวน์โหลดไฟล์ Windows (หรือคัดลอกคำสั่ง PowerShell)
          2. ดับเบิลคลิกไฟล์「เปิดระบบคอมเมนต์」· ถ้า Windows กัน → More info → Run anyway
          3. ครั้งแรกเตรียมเอง — อย่าปิดหน้าต่างดำ
          4. พอ Hub ขึ้น「ทำงานอยู่」= พร้อมไปขั้นที่ 2
          Mac — วิธีที่เปิดได้ทุกเครื่อง (ไม่ติดบล็อกเหลือง)
          1. กดคัดลอกคำสั่งเปิดระบบ
          2. เปิดแอป Terminal (Cmd+Space พิมพ์ Terminal)
          3. วางคำสั่ง (Cmd+V) กด Enter — อย่าปิดหน้าต่าง
          4. พอ Hub ขึ้น「ทำงานอยู่」= พร้อมไปขั้นที่ 2
          หรือดาวน์โหลดไฟล์ (ถ้าขึ้นเหลือง ทำตามนี้)
          1. กดดาวน์โหลด → ถ้าขึ้นสามเหลี่ยมเหลือง กด เสร็จสิ้น (อย่ากดถังขยะ)
          2. การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → เลื่อนลง → เปิดอยู่แล้ว
          ขั้นที่ 2 — กดล็อกอิน แล้วใช้เฟสใน Chrome
          เลือกโปรไฟล์ Chrome ด้านล่าง แล้วเปิด scripts/mac/เปิดChromeจริงสำหรับAgent.command — จะใช้บัญชีที่เคยล็อกอินในโปรไฟล์นั้น (ลดโดน 2FA)
          โปรไฟล์ Chrome บนคอมนี้

          1. เลือกโปรไฟล์จากหน้ารวมด้านบน
          2. เปิด Chrome จริงโหมด Agent (ไฟล์ในเครื่อง)
          3. กดปุ่มด้านล่างให้ระบบเชื่อม · อย่าปิด Chrome
          4. ดูช่อง「รายงานการทำงาน」ว่าสำเร็จ แล้วไปแท็บคอมเมนต์กลุ่ม
          สลับบัญชีกลางทาง: กด「หยุดงานฉุกเฉิน」→ เลือกโปรไฟล์ใหม่ → เปิด Chrome ใหม่ → กด「ทำงานต่อ」

          ถ้ามีปัญหา — อ่านตรงนี้
          • 「ยังไม่เปิด」= ยังไม่ได้เปิดไฟล์ หรือปิดหน้าต่างไปแล้ว → เปิดใหม่
          • Mac ขึ้นสามเหลี่ยมเหลือง = กดเสร็จสิ้น แล้วไป การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → เปิดอยู่แล้ว (หรือใช้ปุ่มคัดลอกคำสั่งในแท็บ Mac)
          • หน้าต่างขึ้น error เรื่อง Browser/Executable = ปิดแล้วเปิดไฟล์ใหม่ ระบบจะดาวน์โหลดเบราว์เซอร์ให้อัตโนมัติ
          • ขึ้นว่าไม่มี Python = ระบบจะติดตั้งให้อัตโนมัติส่วนใหญ่ · ถ้ายังไม่ได้ ให้ติดตั้งตามลิงก์แล้วเปิดใหม่
          • ดาวน์โหลดโปรเจกต์ไม่สำเร็จ = เช็คเน็ตแล้วเปิดไฟล์ใหม่
          • กดล็อกอินแล้วไม่เด้งเฟส = ขั้นที่ 2 ยังไม่เปิด หรือรอให้เตรียมระบบครั้งแรกเสร็จก่อน
