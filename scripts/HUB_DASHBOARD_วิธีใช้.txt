==================================================

หมายเหตุ: บนชีทหลักแท็บ「ทรัพย์รวม」ใช้ค้นหาแบบ FILTER แล้ว
ดู scripts/HUB_OVERVIEW_SEARCH_วิธีใช้.txt และ scripts/install_overview_search_chrome.py
ไฟล์ Apps Script ยังใช้ได้ถ้าต้องการรีเฟรชแบบสคริปต์

แถวบนสุดของแท็บ
---------------
- A1: ชื่อหน้า Property Hub · ทรัพย์รวม …
- แถว 2: 「ค้นหาทั่วไป」+ ช่องเหลือง C2 (รหัส / ชื่อโครงการ)
- แถว 3: 「ค้นหาทำเล/BTS」+ ช่องเหลือง C3 (ทำเล + สถานี)
- A4: สถานะ / จำนวนรายการ
- แถว 5: หัวคอลัมน์ (พื้นทอง #fbbc04)
- A6 ลงไป: ผล FILTER จาก `_overview_src`

ใช้งาน
------
- ว่างทั้ง C2+C3 = แสดงทั้งหมด
- กรอก C2 = กรองรหัส/โครงการ (「ทรู」→ Thru …)
- กรอก C3 = กรองทำเล/BTS
- กรอกทั้งคู่ = AND
- ซิงค์จากแอปจะอัปเดต `_overview_src` โดยไม่ทับแถบค้นหา

ติดตั้งโดยไม่ต้อง Apps Script (แนะนำ)
--------------------------------------
.venv/bin/python scripts/install_overview_search_chrome.py
.venv/bin/python scripts/install_overview_search_chrome.py --resync

Apps Script (ทางเลือก): scripts/google_apps_script_hub_dashboard.gs
