ระบบคอมเมนต์เฟสอัตโนมัติ — อ่านในหน้า Hub จะละเอียดกว่า

วิธีสั้นๆ
---------
1. เปิด Hub → ฐานข้อมูล → คอมเมนต์กลุ่ม
2. อ่านคู่มือบนหน้าเว็บทีละขั้น
3. กดดาวน์โหลดไฟล์ Windows หรือ Mac ตามเครื่องที่ใช้
4. วางไฟล์ในโฟลเดอร์ที่หน้าเว็บบอก → ดับเบิลคลิกเปิดทิ้งไว้
5. กลับไป Hub กดเปิดหน้าต่างล็อกอินเฟส

Windows: วางไฟล์ใน scripts\windows
Mac: วางไฟล์ใน scripts\mac
